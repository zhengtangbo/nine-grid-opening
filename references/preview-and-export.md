# 预览和导出

1. 打开剪映首页，进入同名的本地草稿。新草稿还没出现时，让剪映刷新首页。草稿应包含独立视频轨和一条开场音轨。
2. 核对动画是「动画 → 入场 → 九宫格」。首次使用时，剪映可能需要联网加载资源。若无法预览，选中一段视频并在「入场」里点一次「九宫格」触发加载，再重新打开草稿。用可预览的结果确认所有层的动画。
3. 查看黑底起片、逐层叠入和全屏收尾。默认画面时长约为 `(层数 - 1) × 0.20 + 2.00 + 1.50` 秒。单素材四层约 4.10 秒，六素材约 4.50 秒。检查音频和画面一起结束、原声静音、渐入和渐出可编辑。
4. 有会员时，在剪映导出面板选择合适的本地目的地。采用草稿尺寸、草稿帧率、MP4 和 H.264。通过 FFprobe 检查尺寸、帧率、音视频时长，并解码整个文件。仅在剪映确实已导出时交付 MP4。
5. 无会员时交付草稿并解释导出限制。会员账号如果遇到资源或权益提示，记录实际提示，保留工程。
